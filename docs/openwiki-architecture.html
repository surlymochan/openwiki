Runtime Flow

  1. 1 Load dataset读取 dataset.json、questions.json 和可选 evaluator。
  2. 2 Build indexesraw markdown 建 BM25；mem0 走远端服务或 local fallback；LLM wiki 单独建索引。
  3. 3 Search all routes同一问题同时进入 raw、mem0、wiki 三条召回路线。
  4. 4 Merge and rerank按路线归一化、权重、source hints、问题类型、多路线命中加分排序。
  5. 5 Judge and report输出 retrieval 指标、answer 指标、JSON 报告和 Markdown 对比表。

Raw files + BM25

保底事实召回层，适合精确词、文件路径、政策条款和 abstention 场景。

mem0 semantic

语义记忆层，适合表达差异、多跳线索和非精确匹配问题。

LLM wiki

编译后的知识层，适合跨文档归纳、边界判断和时间线问题。

一句话： OpenWiki 现在评测的是一个企业知识库系统的整体回答能力，而不是某个单独检索器的孤立分数。
system 主能力：raw files + BM25 RAG + mem0 + LLM wiki + rerank。
components 消融对照：单独跑 filesystem 和 mem0，定位是哪层拖累或贡献。
all 完整对比：同时生成 system、filesystem、mem0 的报告和 comparison。
reports 指标包括 accuracy、Recall@1/3/5、MRR、NDCG@5，以及按 question type 分组。
