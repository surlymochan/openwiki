# Governance

## Conflict Handling

If two documents disagree, mark the conflict explicitly and escalate to the owning document maintainer.

## Ownership

Each top-level handbook page must have one named maintainer.

## Change Policy

Allowed during freeze:

1. Correct factual mistakes
2. Add missing owner names
3. Clarify existing procedures without changing behavior

Not allowed during freeze:

1. Introduce a new top-level handbook area
2. Rename ownership domains
3. Change release gates without owner approval
